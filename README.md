# Palas

Приложение для управления хозяйственной деятельностью.

Функции:
- Планирование хозяйственных работ.
- Автоматические напоминания.
- Сезонные и регулярные задачи.
- Прогнозирование сроков обслуживания.
- Работа на компьютере и телефоне.

Пилотные задачи:
1. Покос газона.
2. Контроль заполнения септика.
